# API Reference

Base URL (local Docker): `http://localhost:8000`. Interactive Swagger UI is
auto-generated by FastAPI at `/docs`, and ReDoc at `/redoc` — this document is
a human-oriented summary; treat `/docs` as the source of truth for exact
request/response shapes (`backend/app/schemas.py`).

All endpoints are prefixed `/api`.

## Auth
| Method | Path | Notes |
|---|---|---|
| POST | `/auth/login` | `{username, password}` → `{access_token, role}` |

## Patients / Encounters / Consent
| Method | Path |
|---|---|

| GET | `/patients` |
| GET | `/patients/{id}` |
| GET | `/patients/{id}/encounters` |
| POST | `/encounters` |
| GET | `/encounters/{id}` |
| POST | `/consents` |

## History (adaptive questionnaire)
| Method | Path |
|---|---|
| POST | `/history/start?encounter_id=` |
| POST | `/history/answer` |
| GET | `/history/{encounter_id}` |

`raw_answer: null` + `certainty: "unknown"` records an explicit "unknown" —
never silently converted to a negative answer.

## Clinical facts
| Method | Path |
|---|---|
| POST | `/clinical-facts/extract?encounter_id=&language=` | ASR → normalization → fact |
| GET | `/clinical-facts/{encounter_id}` |
| POST | `/clinical-facts/verify` | `{fact_id, performed_by}` |
| POST | `/clinical-facts/correct` | `{fact_id, new_value, new_label, performed_by}` |
| POST | `/clinical-facts/reject` | `{fact_id, performed_by}` |

## Documents
| Method | Path |
|---|---|
| POST | `/documents/upload?encounter_id=&doc_type=&filename=` |
| POST | `/documents/{id}/process` | Runs mock OCR + extraction; re-runs contradiction detection |
| GET | `/documents/{encounter_id}/list` |

`doc_type` accepts `prescription`, `lab` (→ `lab_report`), or `discharge`
(→ `discharge_summary`).
