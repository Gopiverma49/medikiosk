# MediKiosk API Reference

Base URL (local): `http://localhost:8000`. Interactive Swagger UI is auto-generated by FastAPI at `/docs`, and ReDoc at `/redoc`. Treat `/docs` and `backend/app/schemas.py` as the source of truth for exact request/response schemas.

All REST endpoints are prefixed with `/api`.

---

## 1. Authentication (`/api/auth`)
| Method | Path | Description |
|---|---|---|
| POST | `/auth/login` | `{username, password}` → `{access_token, role, token_type}` |

---

## 2. Patients & Encounters (`/api/patients`, `/api/encounters`, `/api/consents`)
| Method | Path | Description |
|---|---|---|
| POST | `/patients` | Create or update master patient identity (auto-generates 10-digit UHID if omitted) |
| GET | `/patients` | List all registered patients |
| GET | `/patients/{id}` | Get patient details by internal UUID or 10-digit UHID |
| POST | `/patients/lookup` | Search patient by 10-digit UHID and retrieve past treatment records count |
| GET | `/patients/{id}/treatments` | Retrieve past medical history and treatment records |
| GET | `/patients/{id}/encounters` | List all historical check-in encounters for a patient |
| POST | `/encounters` | Start a new outpatient check-in encounter (`mode`, `department`, `previous_illness_id`) |
| GET | `/encounters/{id}` | Get encounter status and details |
| POST | `/consents` | Record patient digital intake consent (`granted: true/false`) |
| POST | `/patients/{id}/prescriptions` | Save prescribed medicines, diagnosis, and doctor notes to patient record |
| GET | `/encounters/{id}/prescription` | Get prescribed medicines and clinical notes for an encounter |

---

## 3. Real-Time Token Queue & Multi-Room Management (`/api/tokens`, `/ws/tokens`)
| Method | Path | Description |
|---|---|---|
| POST | `/tokens/generate` | Issue consultation token for check-in encounter (`encounter_id`, `patient_id`, `department`) |
| GET | `/tokens/queue` | List upcoming and active queue tokens (filterable by `room_id`, `status`, `department`) |
| GET | `/tokens/display-state` | Fetch full multi-room TV board display state with active doctor assignments |
| POST | `/tokens/{id}/call` | Call patient token to a consultation room (`room_id`, `doctor_name`, `doctor_id`) |
| POST | `/tokens/{id}/recall` | Trigger instant recall audio chime broadcast for a patient token |
| POST | `/tokens/{id}/complete` | Mark consultation completed and archive token |
| POST | `/tokens/{id}/cancel` | Cancel or skip patient token |
| GET | `/tokens/rooms` | List active consultation rooms and assigned doctors |
| POST | `/tokens/rooms` | Add or configure consultation room |
| **WS** | `/ws/tokens` | Real-time WebSocket stream for live TV token sync and audible chimes |

---

## 4. History (Dynamic Adaptive Questionnaire) (`/api/history`)
| Method | Path | Description |
|---|---|---|
| POST | `/history/start?encounter_id=` | Initialize adaptive symptom questionnaire for encounter |
| POST | `/history/answer` | Submit question answer (`concept`, `raw_answer`, `certainty`, `source`) |
| GET | `/history/{encounter_id}` | Retrieve full question-and-answer trail for encounter |

> `raw_answer: null` + `certainty: "unknown"` records an explicit unknown — never coerced to a negative answer.

---

## 5. Clinical Facts & Extraction (`/api/clinical-facts`)
| Method | Path | Description |
|---|---|---|
| POST | `/clinical-facts/extract?encounter_id=&language=` | Extract structured clinical facts from text/ASR with confidence scores |
| GET | `/clinical-facts/{encounter_id}` | Get all extracted clinical facts with provenance metadata |
| POST | `/clinical-facts/verify` | Mark fact verified by doctor (`{fact_id, performed_by}`) |
| POST | `/clinical-facts/correct` | Update fact with doctor correction (`{fact_id, new_value, new_label, performed_by}`) |
| POST | `/clinical-facts/reject` | Reject inaccurate extraction (`{fact_id, performed_by}`) |

---

## 6. Documents & OCR (`/api/documents`)
| Method | Path | Description |
|---|---|---|
| POST | `/documents/upload?encounter_id=&doc_type=&filename=` | Upload medical document (`prescription`, `lab`, `discharge`) |
| POST | `/documents/{id}/process` | Run OCR extraction and trigger contradiction detection engine |
| GET | `/documents/{encounter_id}/list` | List all uploaded documents and OCR extractions for encounter |

---

## 7. Red Flags & Triage Screening (`/api/red-flags`, `/api/triage`)
| Method | Path | Description |
|---|---|---|
| GET | `/red-flags/rules` | List all configurable red-flag safety rules and version history |
| POST | `/red-flags/rules` | Create new versioned red-flag safety rule |
| PUT | `/red-flags/rules/{rule_id}` | Update JSON rule conditions and trigger thresholds |
| POST | `/red-flags/rules/{rule_id}/test` | Test rule against simulated facts (`{rule_id, inputs}` → `{fires, priority}`) |
| POST | `/red-flags/rules/{rule_id}/disable` | Enable or disable rule |
| POST | `/triage/evaluate?encounter_id=` | Run triage evaluation engine on encounter facts |
| GET | `/triage/{encounter_id}` | Get triage events and priority classification |

---

## 8. Contradiction Detection (`/api/contradictions`)
| Method | Path | Description |
|---|---|---|
| POST | `/contradictions/detect?encounter_id=` | Scan encounter facts and documents for conflicts |
| GET | `/contradictions/{encounter_id}` | Get detected unresolved and resolved contradictions |
| POST | `/contradictions/{id}/resolve` | Record physician conflict resolution decision (`{decision, resolved_by}`) |

---

## 9. Clinical Summaries (`/api/summaries`)
| Method | Path | Description |
|---|---|---|
| POST | `/summaries/generate?encounter_id=` | Generate structured clinical briefing draft from intake facts |
| GET | `/summaries/{encounter_id}` | Get latest clinical summary draft |
| POST | `/summaries/{id}/confirm` | Physician confirms summary (`status` → `PHYSICIAN_VERIFIED`) |
| POST | `/summaries/{id}/reject` | Reject summary draft |
| POST | `/summaries/{id}/edit` | Edit summary text (`{text, edited_by}`) |

## 10. FHIR R4 & ABDM Mock Integration (`/api/fhir`)
| Method | Path | Description |
|---|---|---|
| GET | `/fhir/status` | Connectivity status (`{"fhir": "READY", "abdm": "MOCK/SANDBOX", "his": "MOCK CONNECTED"}`) |

## 13. Hospital Administration & Audit (`/api/admin`)
| Method | Path | Description |
|---|---|---|
| GET | `/admin/doctors` | List all doctor accounts and status |
| POST | `/admin/doctors` | Create new doctor credential account (`username`, `password`, `full_name`) |
| PUT | `/admin/doctors/{id}` | Update doctor profile or active status |
| DELETE | `/admin/doctors/{id}` | Remove doctor account |
| GET | `/admin/rooms` | List all consultation rooms and pre-assigned doctors |
| POST | `/admin/rooms` | Create consultation room (`name`, `department`, `default_doctor`) |
| PUT | `/admin/rooms/{id}` | Update room configuration |
| DELETE | `/admin/rooms/{id}` | Remove consultation room |
| POST | `/admin/doctors/{id}/assign-room` | Assign doctor to room and broadcast update |
| POST | `/admin/reset-daily-tokens` | Reset daily OPD token queue count |
| POST | `/admin/clear-all-data` | Clear test encounters, tokens, and extractions |
| GET | `/admin/audit-log?limit=` | Retrieve timestamped audit log of all clinical actions |
| GET | `/admin/ai-status` | Check AI providers status (`asr`, `ocr`, `llm`, `tts`, `translation`) |
| POST | `/admin/ai-status/{provider}/toggle` | Toggle provider failure simulation to test fallback resilience |
